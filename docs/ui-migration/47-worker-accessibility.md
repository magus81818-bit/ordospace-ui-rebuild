# Worker accessibility

- Active and Revision queues are named sections; status and attention labels are textual, not color-only.
- Progress uses visible percentages and numeric ARIA values.
- Existing labels, range/number/select/textarea controls, validation alerts, and submit semantics are preserved.
- Save and Submit remain in separately named regions with explicit readiness guidance.
- Readonly states remove forms and retain text explaining the current review state.
- Existing focus-visible behavior is retained. Mobile uses one document scroll with full-width actions and no horizontal overflow.

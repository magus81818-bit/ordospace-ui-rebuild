# Worker detail IA

The detail surface orders task identity, work context, revision reason when applicable, update form, activity, and submission readiness. It uses actual summary, deliverables, phase, status, progress, and QC data.

The existing update panel preserves progress, logged-hours, QC, team-note fields, form state, payload, validation, and save behavior. The existing submission panel preserves its optional note and submit handler. Readonly statuses show the panels' existing state guidance without forms.

At 1280px and above the submission column is sticky. Tablet and mobile return it to document flow; mobile summary fields and actions use one column.

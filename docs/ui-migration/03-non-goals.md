# Round 1 non-goals

Round 1 establishes an isolated, testable functional baseline. It does not:

- apply the SalesOps visual design or dark theme;
- replace the sidebar, header, application shell, or role screens;
- migrate shadcn/Radix primitives or Recharts;
- split or substantially refactor `App.jsx`;
- change domain states, store shape, persistence, route behavior, or copy;
- connect or create a Vercel project;
- fix defects observed in the SalesOps reference.

Those changes require their own migration rounds and acceptance checks.

# Round 9 full state coverage review

## Source

- Consolidated result: `artifacts/redo/r09/full-state-coverage.json`.
- Explicit assertion result: `artifacts/redo/r09/state-assertion-audit.json`.
- Registry source: `tests/redo/r09/state-assertion-registry.cjs`.
- Browser executor: `tests/redo/r09/state-registry-audit.spec.cjs`.
- Primary source artifacts: Round 4 and Round 6 through Round 9 state JSON files.

## Methodology

- Every inventory item is joined to its real primary state artifact.
- Round 3 and Round 5 Matrix-only state names are not accepted as proof.
- Those 40 state keys are explicitly declared in source and executed in a browser.
- Each executed key writes its own evidence image.
- Round 4, 6, 7, 8, and 9 rows resolve through an actual source-state registry.
- The generator records whether a source state or a Round 9 assertion supplied proof.
- Implemented rows require existing evidence and a passing exact registry key.
- Not-applicable rows retain their source reason.
- The validator reconstructs both registries instead of trusting summary totals.

## Pass criteria

- All 73 inventory items must have source-backed state entries.
- Every implemented row must include the required assertion schema.
- `sourceInventoryItemFound` must be true.
- Either `sourceStateFound` or an executed Round 9 assertion must be true.
- `assertionRegistryFile` and `assertionRegistryKey` must resolve exactly.
- Evidence must exist and be generated by the cited assertion path.
- Missing, deferred, invalid, and directory-only evidence counts must be zero.
- Marker-only and broad-title reuse counts must be zero.
- The registry summary flag must be true.

## Risks and limitations

- Primary artifacts reflect the behavior measured in their approved rounds.
- The explicit Round 3 and Round 5 registry covers the Matrix states present now.
- Any new Matrix state requires a new registry key and browser assertion.
- Shared screenshots are accepted only within a related item family and never as a cross-role bridge.
- The audit verifies current source and evidence; it does not claim exhaustive fuzzing.

## Decision

- The prior synthetic marker bridge has been removed.
- Full-state coverage is now traceable to real source state or an exact executed assertion.
